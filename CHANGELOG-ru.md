## [v1.0.0] "Смерть RPG Maker форумов" - 21.08.2026

### Добавлено

- Поддержка и линтинг плагинов Yanfly и подобных. Информация: <https://rpg-maker-translation-tools.github.io/rpgmtranslate-qt/text-editing/#plugin-misc>.
- Реализованы всплывающие подсказки линтов при наведении. Подсказки содержат полезную информацию о тегах.
- Несколько новых линтов, таких как несовпадение тегов, переключаемая проверка орфографии/глоссария.
- Реализована специальная раскраска для тегов вроде \C[x] или \hc[rrggbb].
- Реализованы локальные функции для Git клиента, удалённое взаимодействие ещё не реализовано.
- Реализована поддержка LanguageTool. Платный API LanguageTool не протестирован, только локальный сервер.
- Окно "О программе" теперь показывает информацию об окружении сборки (компилятор, STL, SDK, дата), а также версии ключевых встроенных библиотек (например Nuspell).
- Запущенную задачу (например поиск) теперь можно прервать кнопкой рядом с текстом задачи.
- Приложение теперь предупреждает вас, если файл перевода содержит строки, которые не удалось распарсить, вместо того чтобы молча их пропускать.
- Экспорт/импорт: файлы переводов теперь можно конвертировать в и из CSV, XLSX, XML, JSON и YAML новым пунктом "Экспорт/импорт" в меню кнопки `rv`.
- Кнопка "Отформатировать" просмотрщика ассетов теперь также форматирует JS и Ruby скрипты (через `dprint-plugin-typescript` и `librubyfmt`), а не только JSON.

### Изменено

- Обновлено до `rvpacker-txt-rs-lib` v14.0.0:
    - Файлы теперь сортируются перед чтением, это означает, что они всегда будут в правильном порядке (например actors первый, weapons последний, map001-map999 последовательно).
    - Удалена функция romanize так как она не имела реального значения - "романизация" (или более корректно, латинизация) текста должна выполняться пользователями библиотеки и должна влиять только на перевод - не на исходный текст.
    - Реализован модуль `serde` для экспорта текста в разные структурированные форматы и импорта их обратно. Такие форматы включают CSV, XLSX, YAML, JSON, XML.
- Цвет линтов теперь золотистый по умолчанию.
- Активные линты, их внешний вид и поведение настраиваются через параметры.
- Замены текста на лету (например преобразование `<<` в `«`) теперь настраиваются через параметры.
- Меню массовой обработки теперь работает с кодом JavaScript для выполнения массовых действий. Для реализации использовался quickjs-ng. Он стремится поддерживать новейшие спецификации ECMAScript чтобы вы не были ограничены при написании скриптов.
    - Вы можете создавать свои собственные скрипты! Документацию по тому как это работает в rpgmtranslate-qt можно найти здесь: <https://rpg-maker-translation-tools.github.io/rpgmtranslate-qt/batch-processing/>.
- Микрооптимизированы разные части программы.
- Отслеживание текущей задачи в верхней панели теперь более информативно.
- Меню массовой обработки теперь имеет два выбираемых действия, "перевод" и "скрипт". "скрипт" имеет три встроенных скрипта, включая обрезку и перенос из прошлого, и новый скрипт латинизации.
- Селекторы исходного/целевого языка переработаны для отображения полного спектра человеческих языков. Ранее эти поля включали только языки поддерживаемые бэкендом Snowball. Если язык не поддерживается [Snowball](https://snowballstem.org/algorithms/) (или LSTM сегментацией), он не будет поддерживать стемминг и уведомит вас об этом.
- Меню совпадения терминов переработано как общее меню для линтов. Таблица упрощена чтобы показывать общие линты о несовпадениях тегов, несовпадениях пунктуации, опечатках, несовпадениях терминов и всём остальном.
- Активные линты и другие проверки переводов теперь переключаются в новом меню линтов. Это позволяет вам переключать линты сразу же, однако линты всё ещё настраиваются в параметрах.
- Логирование значительно улучшено, теперь оно должно охватывать больше частей приложения и быть лучше в целом.
- Каждая задача теперь запускается в собственном выделенном потоке, что позволяет вам запускать несколько задач одновременно.
- API ключи (точки перевода, LanguageTool) больше не хранятся в `settings.json`. Они теперь находятся в хранилище учетных данных ОС (Windows Credential Manager / Linux Secret Service) и читаются в память только при необходимости.

### Фиксы

- Git клиент/панель вкладок теперь скрываются перед открытием проекта.
- Git клиент/панель вкладок теперь скрываются и Git клиент правильно сбрасывается при закрытии проекта.
- Исправлены проблемы возможно связанные с хешированием из-за хеширования мусора после нулевого терминатора.
- Исправлена загрузка неправильных хешей из параметров проекта, что вызвало бы всплывающее окно с сообщением что файлы обновлены, когда на самом деле они не обновлялись.
- Исправлено отображение меню на неправильной Y позиции на Windows.
- Исправлены неправильные значения столбца перевода / точки перевода в меню массовой обработки.
- Исправлены сломанные меню выбора файла, которые были сломаны по какой-то причине. Или может это регрессия которая никогда не была отправлена в кандидатах релиза.
- Таблица переводов теперь прокручивается горизонтально пиксель за пикселем что удобнее.
- Действие "запись" на панели инструментов больше не показывает ложное сообщение "успешно записано" после того как запись на самом деле не удалась.
- Окно параметров больше не записывает устаревший индекс точки перевода после того как эта точка была только что удалена.
- Метка процента масштабирования в просмотрщике ассетов теперь правильно показывает знак `%`.
- Масштабирование по размеру в просмотрщике ассетов (при открытии изображения или обновлении примера шрифта) теперь работает корректно.
- Исправлена ошибка копирования где точка перевода Mistral случайно использовала API Moonshot для перевода одной ячейки.

### Разработка

- Скрипты конфигурации перенесены на Lua и начато распространение минимальных билдов Lua для Windows/Linux для запуска скриптов конфигурации. Модифицированные источники Lua можно найти здесь: <https://github.com/savannstm/lua>.
- Парсинг/запись JSON теперь использует Glaze, что более поддерживаемо.
- Пересмотрены флаги используемые для билда проекта на Windows - теперь должно быть более оптимизировано и меньше ошибок. Я также обрезал встроенный билд данных ICU, так что сырой исполняемый файл теперь занимает меньше места.
    - Что-то повредило бинарники после сжатия их через UPX, который мы использовали для каждого релиза и приложение крашилось при запуске - #12. Проблема была в сжатых экспортах. После переупаковки с `--compress-exports=0`, проблема исчезла, так что теперь наши сжатые распространяемые бинарники **менее 20МБ**!
- Теперь мы поставляем лицензии для всех библиотек которые мы статически линкуем. Лицензии можно найти в директории `licenses`, и окно "О программе" теперь содержит информацию о таких библиотеках. Это наше юридическое обязательство, но я также решил включить библиотеки которые не требуют указания авторства.
- Добавлен скрипт `prepare-release.lua` для упаковки релиза который проверяет что каждая встроенная библиотека имеет задокументированный текст лицензии, генерирует уведомление о библиотеках третьейстороны, сжимает построенный бинарник через UPX и пакует итоговый архив релиза.
- Документация (параметры, git, массовая обработка, глоссарий, редактирование текста) была обновлена чтобы отражать текущее состояние программы и её возможностей.
- Официальные релизы теперь нацелены на архитектуру x86-64-v3 (вместо предыдущих билдов на архитектуру Sandy Bridge) - начиная с Intel Haswell (2013) и AMD Excavator (2015). Это позволяет использовать AVX2, FMA и BMI чтобы значительно улучшить производительность. Если вам нужна сборка поддерживающая более старые процессоры, вам придется собирать из исходников.
- JS скрипты приложения по умолчанию теперь можно найти в директории `scripts`.
- Заменен ручной алгоритм подсветки через tree-sitter (аллокация буферов, инкрементальный `QSyntaxHighlighter`, закрепление цвета за токеном) на [lumis](https://github.com/leandrocp/lumis): Rust теперь сразу же передает HTML, и просмотрщик кода просто его загружает.
- Исправлена давняя опечатка в опции CMake для подсветки синтаксиса JS что означало что она никогда не была включена, независимо от значения.
