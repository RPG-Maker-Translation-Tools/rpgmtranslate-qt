---
title: "Функции rvpacker"
---

`rvpacker-txt-rs-lib` отвечает за чтение текста из RPG Maker игр и его запись обратно. Он состоит из четырёх частей.

## Чтение

Чтение расшифровывает исходный архив (если нужно), парсит файлы данных игры и создаёт текстовые файлы, которые вы редактируете.

Когда вы впервые открываете новый проект, перед парсингом автоматически появляется диалог с опциями чтения - чтобы продолжить, его нужно настроить и нажать "Применить". Позже вы можете вручную запустить повторное чтение кнопкой `rv` (выберите "Чтение" в её меню), чтобы перепарсить проект, например после того как игра обновилась и её исходные файлы изменились. Это открывает тот же диалог:

| Опция                                   | Действие                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Режим чтения                            | **Стандартный** парсит текст игры; он используется только для первого чтения и не может быть выбран, когда у проекта уже есть файлы перевода. **Принудительный** перепарсивает всё и **перезаписывает существующие файлы перевода, уничтожая ваш перевод**. **Добавление** (по умолчанию для ручного повторного чтения) добавляет новый найденный текст, не уничтожая существующий перевод, но ничего не делает, если исходные файлы не изменились с последнего чтения; **Принудительное добавление** добавляет в любом случае. В режимах добавления режим дубликатов и кодировка текста зафиксированы на значениях первого чтения. |
| Режим дубликатов                        | **Разрешить дубликаты** (по умолчанию и рекомендуемый режим) сохраняет каждое вхождение отдельно, так что у каждого свой перевод. **Удалить дубликаты** схлопывает повторяющиеся строки в картах и ивентах. Файлы System, scripts и plugins всегда обрабатываются так, будто дубликаты разрешены, независимо от этой опции.                                                                                                                                                                                                                                                                                                         |
| Кодировка текста                        | Декодирует текст игры в указанной кодировке. По умолчанию UTF-8. У RPG Maker 2000/2003 нет собственной кодировки, они используют кодировку системы, так что задайте её для них. XP и VX, как правило, используют UTF-8 (RGSS устанавливает `$KCODE` в UTF-8), но игра _наверное может_ переопределить это: меняйте только если текст выходит искажённым. Текст, который не декодируется, сообщается как ошибка. Если в названии игры ниже есть национальные, не-ASCII символы, оно _возможно может_ помочь определить правильную кодировку.                                                                                         |
| Кодировка архива                        | Декодирует названия файлов внутри архива RGSS (XP, VX, VX Ace), который распаковывается при первом открытии проекта. По умолчанию UTF-8. Показывается только для этих движков и только при первом чтении проекта, в котором ещё есть архив (не когда папка data уже существует).                                                                                                                                                                                                                                                                                                                                                    |
| Игнорирование                           | Пропускает строки, перечисленные в файле `.rvpacker-ignore` (см. [чистку](#чистка)).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Пропустить устаревшее                   | Удаляет строки прошлого чтения, которых больше нет в исходных файлах, вместо того чтобы сохранять их.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Распарсить ивенты карт                  | Также извлекает метаданные ивентов карт - ID, название и позицию X/Y - вместе с текстом диалогов.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Использовать название игры из ini файла | Для RPG Maker 2000/2003/XP/VX/VX Ace название игры не всегда есть в system файле. Включите эту опцию, чтобы взять его из `Game.ini` (XP/VX/VX Ace) или `RPG_RT.ini` (2000/2003), смотря какой файл есть. У названия свой выбор кодировки; если название, показанное под ним, выходит искажённым, кодировка неверна.                                                                                                                                                                                                                                                                                                                 |

Принудительное чтение спрашивает подтверждение, прежде чем перезаписать файлы перевода. Кнопка выбора файлов в диалоге позволяет ограничить ручное повторное чтение отмеченными файлами. Файлы карт перечитываются всегда, отмечены они или нет.

## Запись

Запись доступна через кнопку ![](../assets/manufacturing.svg). Она записывает ваш текущий перевод всех файлов обратно в файлы игры, готовые к запуску. Результат записи помещается в `ПАПКА_ПРОЕКТА/.rpgmtranslate/output` - это всё, что нужно для применения перевода к игре: скопируйте содержимое `.rpgmtranslate/output` в папку игры.

Запись можно запустить горячей клавишей `Ctrl+W`.

Для RPG Maker 2000/2003 важна кодировка текста при записи; остальные движки используют UTF-8. Подробнее в [настройках](./settings.md#проект).

## Чистка

Чистка избавляется от непереведённых строк и может по желанию создать файл `.rvpacker-ignore`, чтобы эти строки не появлялись снова при следующем чтении проекта с включённым "Игнорированием". У неё своё меню выбора файлов (как и при чтении, файлы карт чистятся всегда), она спрашивает подтверждение, прежде чем что-либо удалить, а после завершения она заново открывает проект.

## Экспорт/импорт

Конвертирует ваши файлы перевода в CSV, XLSX, XML, JSON или YAML и обратно - полезно для редактирования в таблице, отправки тому, кто не хочет запускать приложение, или архивации снимка вне собственного формата приложения.

Выберите формат, папку (назначение для экспорта, источник для импорта), отметьте нужные файлы в меню выбора файлов, затем нажмите "Экспорт" или "Импорт". Каждый файл перевода становится одним файлом выбранного формата в этой папке, с тем же названием и другим расширением (например `actors.txt` -> `actors.csv`) - импорт ожидает такие же названия обратно.

Если не отмечен ни один файл, вас попросят выбрать их. Экспорт создаёт папку, если её ещё нет. **Импорт перезаписывает содержимое соответствующего файла перевода** и сначала спрашивает подтверждение, так что убедитесь, что в папке, из которой вы импортируете, действительно то, что нужно.
