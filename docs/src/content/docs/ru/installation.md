Билды публикуются на странице [Releases](https://github.com/RPG-Maker-Translation-Tools/rpgmtranslate-qt/releases) в виде портабельных архивов. Билды для Linux (архив и AppImage) собираются и загружаются воркфлоу GitHub, когда создаётся тег версии. Билд для Windows собирается и загружается вручную.

## Требования

**CPU.** Каждый опубликованный релиз нацелен на **x86-64-v3**, что требует инструкций AVX, AVX2, BMI1, BMI2, F16C, FMA, LZCNT и MOVBE. На практике это означает Intel начиная с Haswell (2013) или AMD начиная с Excavator (2015). Для более старого железа придётся [собрать программу из исходников](development.md) с более низким `-march`.

**ОС.** Релизы для Windows требуют Windows 10 или 11. Linux будет работать, пока в системе есть libstdc++14/libc++23 или новее.

## Обновления

RPGMTranslate проверяет наличие нового релиза при запуске (это переключается в [Настройки > Основные](settings.md#обновления)), или по запросу через `Помощь > Проверить обновления`. Если существует новая версия, вас спросят, прежде чем что-либо скачивать и устанавливать - ничего не происходит автоматически в фоне. Обновление заменяет исполняемый файл (или AppImage) и файлы лицензий, которые поставляются вместе с ним.

В билдах с отключённым самообновлением (`ENABLE_UPDATER=OFF`, например в пакете дистрибутива) эта настройка отключена, а `Помощь > Проверить обновления` лишь сообщает, что билд не может обновить сам себя.

### Релизы

Исполняемые файлы сжаты через:

```bash
upx --best --lzma --brute --ultra-brute --compress-exports=0
```

## Файлы данных программы

RPGMTranslate портативен. По умолчанию он хранит свои данные в папке исполняемого файла:

| Файл / папка            | Назначение                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| `settings.json`         | [Файл настроек](settings.md)                                                                           |
| `rpgmtranslate.log`     | Лог файл текущей сессии                                                                                |
| `scripts/`              | Ваши [пользовательские скрипты](batch-processing.md#пользовательские-скрипты)                          |
| `dictionaries/`         | Словари для проверки правописания, см. [проверку правописания](settings.md#проверка-правописания)      |
| `lindera-dictionaries/` | Словари для сопоставления терминов CJK, см. [проверку терминов CJK](settings.md#проверка-терминов-cjk) |

Если вы хотите проигрывать MIDI файлы в [просмотрщике ассетов](asset-inspector.md#midi), вам также нужно положить туда же файл `soundfont.sf2`. Приложение не создаёт и не поставляет его.

Лок для одной инстанции приложения, `rpgmtranslate.lock`, хранится во временной папке системы. Пока одна инстанция запущена, запуск второй ничего не делает.

Установите переменную среды **`RPGMTRANSLATE_DATA_DIR`**, чтобы хранить данные в другом месте:

```bash
RPGMTRANSLATE_DATA_DIR=/home/chuck-norris/.config/rpgmtranslate rpgmtranslate
```

Это важно, когда приложение находится в месте, где нельзя записывать файлы - в `/usr/local/bin` или в `Program Files`. Если переменная не установлена, а в папку исполняемого файла нельзя записывать, приложение использует системную папку данных приложений текущего пользователя (`%LOCALAPPDATA%\rpg-maker-translation-tools\rpgmtranslate` на Windows, `~/.local/share/rpg-maker-translation-tools/rpgmtranslate` на Linux).

Если вы пакуете RPGMTranslate для дистрибутива, установите `RPGMTRANSLATE_DATA_DIR` глобально, или пропатчите значение по умолчанию в `main()` в `src/main.cpp`.

## Лицензии

Статические релизы под Windows поставляют лицензии всех статически слинкованных библиотек (включая зависимости Rust и транзитивные зависимости) в папке `licenses` рядом с релизом.

`THIRD-PARTY-NOTICE.md` рядом с релизом поставляется, чтобы помочь вам найти нужную лицензию (если она вам вообще понадобится).

На других платформах поставляются только лицензии header-only библиотек, находящихся в репозитории.
