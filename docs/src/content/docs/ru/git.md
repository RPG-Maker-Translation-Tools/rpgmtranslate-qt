RPGMTranslate имеет встроенный гит клиент для отслеживания прогресса перевода. Он нацелен на локальный контроль версий - поддержка удалённых репозиториев ограничена пушем, а некоторые элементы управления ещё подключаются.

Он открывается кнопкой ![](../assets/commit.svg).

## Настройка

Репозиторий находится в папке проекта `.rpgmtranslate`, а не в самой папке игры. Если она ещё не является гит репозиторием, вы увидите кнопку "Создать репозиторий", которая инициализирует его и запишет `.gitignore`, исключающий резервные копии и исходную копию данных игры (существующий `.gitignore` сохраняется).

Данные автора коммитов настраиваются в [Настройки > Основные > Git](./settings.md#git): либо ваши собственные имя/почта, либо "использовать конфигурацию репозитория", чтобы брать данные из `git config`, уже заданного для репозитория.

## Работа с изменениями

- Список изменений показывает каждый изменённый/добавленный/неотслеживаемый/удалённый/переименованный файл со значком статуса для каждого.
- Кликните по флажку файла, чтобы застейджить его или убрать из стейджа.
- Кнопка обновления заново сканирует рабочую папку на изменения.
- "Скопировать перевод в корень" копирует `.rpgmtranslate/translation` в папку `translation` в папке игры, перезаписывая файлы там - удобно, если вы храните файлы перевода в репозитории самой игры.

## Коммиты

Введите сообщение коммита и закоммитьте как обычно, или используйте меню рядом с кнопкой коммита:

- **Коммит (добавление)** - дополняет предыдущий коммит вместо создания нового.
- **Коммит и пуш** - коммитит и сразу пушит в `origin`.

## Брэнчи

Переключатель брэнчей перечисляет локальные и удалённые брэнчи (помечены отдельно) и позволяет переключаться между ними. Создание и удаление брэнчей из интерфейса пока недоступно.

## История

История коммитов показывает ваш локальный лог коммитов. Пока она только для отображения - клик по коммиту ещё не показывает его дифф.

## Известные ограничения

Над клиентом ещё ведётся работа:

- Пока нет просмотра диффа изменений файла.
- Пока нет отката файла к исходному состоянию. Пункты "Стейджануть выбранное" и "Откатить выбранное" контекстного меню списка изменений пока ничего не делают.
- Пока нет интерфейса для пулла/фетча, стэша, тегов и управления удалёнными репозиториями - для `git pull`/фетча и удалённых брэнчей всё ещё нужна обычная командная строка или другой гит клиент.
