![](../assets/settings.svg) Настройки открываются через меню "Файл".

Окно разбито на пять разделов, перечисленных слева: **Основные**, **Внешний вид**, **Управление**, **Перевод**, **Проект**. В окне есть кнопки **Сохранить** и **Отмена**. "Сохранить" применяет изменения; если в поле неверное значение (например, период резервного копирования вне диапазона), окно откажется закрываться и укажет вам на ошибочное поле. "Отмена", `Esc` и кнопка закрытия отбрасывают все изменения, включая стиль, тему и удалённые точки перевода. Настройки нельзя открыть, пока выполняется [задача](./tasks.md).

Основные настройки, внешний вид, управление и перевод хранятся глобально, в `settings.json`. Только раздел "Проект" хранится **отдельно для каждого проекта** (в `.rpgmtranslate/project-settings.json`), так что разные проекты могут использовать разные языки, словари и лимиты длины строки, но общие точки перевода и конфигурацию линтинга. Раздел "Проект" действует только когда проект открыт.

## Основные

### Резервное копирование

| Параметр                      | Описание                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------ |
| Включено                      | Включает или отключает автоматическое резервное копирование проектов.          |
| Период резервного копирования | Как часто создаётся резервная копия, в секундах (60-3600).                     |
| Максимум резервных копий      | Сколько резервных копий хранить на проект перед удалением самой старой (1-99). |

Чтобы восстановить копию, используйте `Файл > Загрузить резервную копию`. Это меню перечисляет резервные копии проекта по дате и предупреждает, что загрузка **перезапишет вашу текущую несохранённую работу** - сначала убедитесь, что вы этого хотите.

| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Шрифт таблицы переводов / размер | Шрифт и размер (8-96 пт), используемые в таблице переводов.                                                                                 |
| Стиль                            | Стиль виджетов Qt - влияет на внешний вид кнопок, списков и других элементов.                                                               |
| Тема                             | Светлая, тёмная или системная (стандартная).                                                                                                |

## Управление

Горячие клавиши для открытия панелей и меню. Кликните по полю горячей клавиши и нажмите нужную комбинацию.

| Действие              | По умолчанию   |
| --------------------- | -------------- |
| Панель поиска         | `Ctrl+R`       |
| Панель вкладок        | `Tab`          |
| Переход к строке      | `Ctrl+G`       |
| Меню обработки        | `Ctrl+B`       |
| Меню закладок         | `Alt+B`        |
| Меню линтов           | `Ctrl+M`       |
| Меню глоссария        | `Alt+L`        |
| Меню переводов        | `Alt+T`        |
| Обрезать ячейку       | `Ctrl+Shift+T` |
| Перенести ячейку      | `Ctrl+Shift+W` |
| Латинизировать ячейку | `Ctrl+Shift+L` |

Последние три запускают встроенные [скрипты обрезки, переноса и латинизации](./batch-processing.md) на редактируемой ячейке (или выбранной ячейке перевода), так что для одной ячейки не нужно открывать меню обработки. Обрезка удаляет начальные и конечные пробелы, а перенос использует лимит длины строки проекта (если он равен 0, вас попросят его указать). Пока ячейка открыта для редактирования, изменение можно отменить через `Ctrl+Z`.

Одна и та же горячая клавиша не может быть назначена на два из этих действий одновременно - попытка сохранить с дубликатом будет отклонена, пока вы не измените одну из них. То же самое касается назначения одной из фиксированных горячих клавиш ниже.

Для горячих клавиш есть особые случаи, которые нельзя изменить:

| Действие                                                | По умолчанию                                                                                                        |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Сохранение                                              | [QKeySequence::Save](https://doc.qt.io/qt-6/qkeysequence.html#standard-shortcuts) (Ctrl+S)                          |
| Запись                                                  | Ctrl+W                                                                                                              |
| Поиск                                                   | [QKeySequence::Find](https://doc.qt.io/qt-6/qkeysequence.html#standard-shortcuts) (Ctrl+F)                          |
| Закрытие вкладки                                        | Esc                                                                                                                 |
| Копировать / Вырезать / Вставить / Отменить / Повторить | Стандартные горячие клавиши платформы ([QKeySequence](https://doc.qt.io/qt-6/qkeysequence.html#standard-shortcuts)) |

## Перевод

Это самый большой раздел. Здесь настраиваются точки машинного перевода, LanguageTool и система линтинга.

API ключи хранятся в собственном хранилище учётных данных ОС (Windows Credential Manager или Secret Service keyring на Linux), а не в `settings.json`, и считываются только при необходимости. Если хранилище отказывается принять ключ, он остаётся в `settings.json`, и вы получаете предупреждение.

### Точки перевода

Точки перечислены слева в этом разделе; добавляйте или удаляйте их кнопками рядом со списком, а чтобы переименовать точку, дважды кликните по ней. Каждая точка опрашивается, когда вы начинаете редактировать ячейку, см. [машинный перевод](./text-editing.md#машинный-перевод). Поля зависят от типа точки:

- **Google** - бесплатно, настройка не требуется.
- **Yandex** - требует API ключ и ID папки Yandex Cloud. "Проверить ключ" проверяет ключ.
- **DeepL** - требует API ключ. "Проверить ключ" проверяет ключ.
- **Script** - запускает предоставленный вами JavaScript файл, так что можно подключить любой сервис перевода или ИИ модель. Файл определяет `rpgmTranslateCallback(text, sourceLanguage, translationLanguage, glossary, filename)` и возвращает переведённый текст строкой. `glossary` - массив включённых терминов [глоссария](./glossary.md) вида `{ term, translation, note }`, и он пуст, если у точки не включён флажок "Использовать глоссарий". При закрытии настроек вас один раз для каждой версии скрипта спросят, может ли он запускать программы и читать или записывать файлы; неразрешённый скрипт не будет запускаться. Функции, доступные скриптам, и пример для Ollama описаны в [массовой обработке](./batch-processing.md#что-могут-скрипты).

Бэкэнд, не включённый в билд (см. [разработку](./development.md#опции-без-дополнительных-библиотек)), всё равно можно выбрать, но его описание предупреждает, что он не был скомпилирован в билд, и его использование не удастся.

### LanguageTool

Настраивает проверку грамматики [LanguageTool](https://languagetool.org/), используемую для [линтинга](./text-editing.md#линтинг). Настройки поддерживают и локальный сервер, и платный хостинг, но протестирован нами только локальный сервер.

| Параметр                                                         | Описание                                                                                                                   |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Базовый адрес                                                    | Ваш сервер LanguageTool, локальный или хостинг. "Проверить подключение" проверяет его доступность.                         |
| Имя пользователя / API ключ                                      | Нужны только для платного хостинга, для доступа к Premium.                                                                 |
| Родной язык                                                      | Ваш родной язык, для проверки ложных друзей переводчика в некоторых языковых парах.                                        |
| Только включённые                                                | Если включено, проверяются только явно указанные ниже категории/правила - всё остальное игнорируется.                      |
| Включённые/отключённые категории, включённые/отключённые правила | ID правил/категорий через запятую, чтобы сузить или урезать проверяемое.                                                   |
| Предпочтительные варианты                                        | Региональные варианты написания через запятую, которые LanguageTool должен предпочитать (например `en-US` вместо `en-GB`). |
| Словари                                                          | Дополнительные словари через запятую, из которых брать слова. Оставьте пустым для словаря по умолчанию.                    |
| Строгий режим                                                    | Включает дополнительные правила, в основном полезные для формального текста.                                               |

### Слова и символы

"Отображать количество слов/символов для файла" показывает в строке состояния, сколько слов и символов в исходном тексте и в первом столбце перевода открытого файла. Счётчики обновляются вслед за вашими правками вскоре после того, как вы покидаете ячейку, а подсказка также показывает количество символов без пробелов.

Это те счётчики, по которым переводчик выставил бы счёт, и коды RPG Maker (`\C[2]`, `\N[1]`, `<br>` и так далее) не считаются:

- **Слова** - это словоподобные отрезки текста: буквы, числа и иероглифы/кана CJK, но не пробелы и не пунктуация. `don't` и `3.14` - одно слово, `well-known` - два. Японский, китайский, тайский, лаосский, кхмерский и бирманский, в которых нет пробелов между словами, разбиваются встроенным словарём, так что японский исходный текст тоже получает разумное количество слов.
- **Символы** - это то, что читатель видит как один символ (буква с диакритикой или эмодзи - один символ), включая пробелы.

**Файл > Статистика проекта** считает все файлы проекта разом (открытая вкладка сначала сохраняется) и показывает счётчики по файлам с итогами внизу.

### Линтинг

Всё здесь также можно включать и отключать по отдельности кнопкой "Линты" в [меню линтов](./text-editing.md#линтинг) - здесь же вы их настраиваете и редактируете, а не просто включаете/отключаете.

- **Линты последовательностей** - четыре таблицы только для чтения (текстовые коды, теги в заметках, команды плагинов, теги в комментариях), перечисляющие все встроенные шаблоны плагинов/тегов, которые распознаёт RPGMTranslate, сгруппированные по категориям. Каждой строке можно задать свой цвет подсветки.
- **Особые линты** - ваши собственные шаблоны линтов в редактируемой таблице: последовательность для совпадения, подсказка при наведении, учёт регистра и необязательный цвет подсветки. Дважды кликните по ячейке, чтобы отредактировать её. Особые линты можно экспортировать в JSON файл и импортировать из него, чтобы сделать резервную копию или поделиться ими.
- **Другое**:
  - Замена последовательностей - таблица последовательностей символов, которые молча заменяются при вводе (например `<<` -> `«`), полезно для не-ASCII пунктуации, которой нет на клавиатуре. Несколько распространённых предзаполнены, но по умолчанию отключены.
  - Символы пробелов - какие кодовые точки Unicode (`U+XXXX`, через запятую) считаются пробелом для линтов начальных/конечных/повторяющихся пробелов.

## Проект

Хранится отдельно для каждого проекта.

| Параметр                      | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Лимит длины строки            | Рисует тонкую красную линию в ячейке перевода на этом количестве символов (0-255) как ориентир для переноса.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Исходный язык / Язык перевода | Исходный и целевой языки, используются для многих разных вещей.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Словарь для правописания      | Словарь Nuspell, по которому проверяется текст. Где его взять, см. ниже.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Кодировка для записи          | Перевод, как правило, невозможно представить в исходной кодировке игры (в японской `Shift-JIS`, например, нет кириллицы для русского перевода), а текст, который нельзя закодировать в выбранной кодировке, проваливает весь файл с ошибкой вместо записи в виде ссылок вида `&#1055;`. По умолчанию UTF-8, что подходит для XP, VX, VX Ace, MV и MZ (XP и VX, как правило, используют UTF-8, потому что RGSS устанавливает `$KCODE` в UTF-8, хотя игра _наверное может_ это переопределить). Меняйте её только для RPG Maker 2000/2003, которые используют устаревшую ANSI кодировку ОС, или для игры, переопределяющей `$KCODE`, и только если письменность перевода умещается в выбранную кодировку. Тому, кто будет запускать переведённую игру, тогда тоже придётся выставить в системе (или через эмулятор локали) ту же кодировку; начиная с Windows 10 1903 включение флажка "Бета-версия: использовать Юникод (UTF-8) для поддержки языков во всём мире" в настройках региона позволяет выводу в UTF-8 по умолчанию работать и для RPG Maker 2000/2003 без всего вышеперечисленного. |

### Лимит длины строки

Лимит - это примерная оценка того, сколько символов помещается в одну строку в игре, поэтому линия рисуется на фиксированной позиции и не двигается вместе с вводимым текстом. Она ставится на среднее двух средних ширин символов шрифта: печатных ASCII символов и фиксированного набора пунктуации, каны и кандзи CJK (переводчики часто оставляют пунктуацию CJK в переводе).

- **Шрифт подсказки** - шрифт, который использует ваша игра. Он не меняет внешний вид редактора; он используется только чтобы решить, когда строка слишком длинная.
- **Размер шрифта подсказки** - базовый размер шрифта сообщений игры в пикселях (`0` означает 28, значение по умолчанию в MV/MZ). Он позволяет учитывать теги размера, такие как `\{`, `\}` и `\fs[n]`.

Рядом со слишком длинной строкой текста линия рисуется более насыщенным красным.

### Проверка правописания

RPGMTranslate не поставляется со словарями для проверки правописания - положите файлы `.aff`/`.dic` в папку `dictionaries` [папки данных приложения](./installation.md#файлы-данных-программы) (вложенные папки допускаются), и они появятся в выпадающем списке выше. Источники:

- [Словари LibreOffice](https://github.com/LibreOffice/dictionaries)
- [Эта коллекция словарей](https://github.com/wooorm/dictionaries)

CJK пока не поддерживается.

### Проверка терминов CJK

[Сопоставление глоссария](./glossary.md) для японского, китайского и корейского требует словарей для разделения слов (в этих языках нет пробелов между словами), и RPGMTranslate их тоже не поставляет - они весят сотни мегабайт и раздули бы каждую установку. Скачайте подходящий архив со [страницы релизов Lindera](https://github.com/lindera/lindera/releases) и распакуйте его, затем переместите файлы из распакованной папки (`dict.trie`, `dict.words`, `metadata.json` и т.д.) в `lindera-dictionaries/<язык>` в [папке данных приложения](./installation.md#файлы-данных-программы), так чтобы `dict.trie` и остальные лежали прямо в ней. Папки ищутся при запуске приложения, так что перезапустите его после добавления словаря:

| Язык      | Папка                           | Архив для скачивания                                                                               |
| --------- | ------------------------------- | -------------------------------------------------------------------------------------------------- |
| Японский  | `lindera-dictionaries/japanese` | `lindera-ipadic-neologd-*.zip` (лучшее качество сопоставления) или `lindera-ipadic-*.zip` (меньше) |
| Китайский | `lindera-dictionaries/chinese`  | `lindera-cc-cedict-*.zip`                                                                          |
| Корейский | `lindera-dictionaries/korean`   | `lindera-ko-dic-*.zip`                                                                             |

Если папка языка отсутствует, пуста или её файлы оказались во вложенной подпапке, сопоставление для этого языка завершится ошибкой, а не будет молча использовать что-то другое.
