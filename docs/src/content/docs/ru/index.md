title: "RPGMTranslate"
---

RPGMTranslate - это простой инструмент для перевода RPG Maker игр с открытым исходным кодом. Среди его основных преимуществ - невероятная производительность и простой текстовый формат файлов перевода.

Само приложение представляет собой портабельный исполняемый файл. Всё, что приложение записывает, старается оставаться рядом с ним - настройки, лог, пользовательские скрипты и так далее. Папка для данных приложения может быть изменена через переменную среды `RPGMTRANSLATE_DATA_DIR`, прочтите [установку](installation.md#файлы-данных-программы).

## Как начать

Чтобы начать переводить что-либо, вам лишь нужно ![](../assets/folder_open.svg) открыть папку, содержащую RPG Maker игру. Более конкретно, папка должна содержать папку `data` (или `Data`), архив RGSS (`Game.rgssad`, `Game.rgss2a`, `Game.rgss3a`) или же файл `RPG_RT.ldb` движка RPG Maker 2000/2003.

Когда вы впервые открываете новый проект, перед чтением файлов появляется диалоговое окно с опциями чтения - выберите опции (или оставьте стандартные) и нажмите "Применить". Прочтите [Rvpacker > Чтение](rvpacker.md#чтение), чтобы понять, что делает каждая опция. После этого приложение расшифрует архив, если нужно, вытащит текст из файлов папки data, создаст папку `.rpgmtranslate` и откроет проект.

Отсюда вы можете начать делать всякое. Не знаете, с чего начать? [Установка](installation.md) и [редактирование текста](text-editing.md) - лучшие места для начала.
