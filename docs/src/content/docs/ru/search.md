Откройте меню поиска кнопкой ![](../assets/search.svg) (`Ctrl+F`). Введите текст в поле поиска и нажмите кнопку поиска, чтобы запустить его. Поля ввода многострочные, так что Enter вставляет новую строку, а не запускает поиск.

Одни и те же поле и опции управляют тремя разными действиями - **поиском**, **заменой** и **помещением** - они описаны ниже в порядке опасности. Поиск лишь ищет; замена и помещение записывают в ваш перевод, так что прочтите их разделы, прежде чем использовать их на чём-то, что вам жалко потерять.

Прежде чем что-либо запускать, выберите файлы в меню выбора файлов - по умолчанию ни один файл не выбран. В нём есть кнопки "Выбрать всё" и "Убрать всё", а протягивание мыши по флажкам переключает каждый, через который вы проходите.

## Опции поиска

Эти опции применяются ко всем трём действиям:

| Опция                          | Эффект                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| Поиск по регистру              | Учитывать регистр.                                                                                           |
| Поиск целиком                  | Совпадают только целые слова.                                                                                |
| Поиск по регулярным выражениям | Текст поиска используется как регулярное выражение - см. [регулярные выражения](#регулярные-выражения) ниже. |
| Поиск в комментариях           | Также ищет в строках комментариев, которые по умолчанию пропускаются.                                        |
| Выбор файлов                   | Файлы для обработки.                                                                                         |
| Локация                        | Искать везде, только исходный текст или только перевод.                                                      |
| Столбец                        | Все столбцы, крайний столбец или любой другой столбец перевода.                                              |

## Поиск

Поиск лишь находит совпадения и перечисляет их - он никогда ничего не меняет. Результаты появляются в ![](../assets/dock.svg) панели результатов (`Ctrl+R`), по умолчанию закреплённой справа (перетащите её, чтобы открепить, если она нужна в другом месте). Панель может фильтровать результаты по файлу, а её кнопка очистки очищает её.

Поиск сильно оптимизирован: совпадения хранятся как плотно упакованные индексы в памяти, так что даже проект с миллионами совпадений остаётся отзывчивым.

Действия с каждым совпадением в панели результатов:

| Кнопка  | Действие                                                                                                                                                                                                                                            |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Левая   | Перейти к этому совпадению в таблице перевода.                                                                                                                                                                                                      |
| Правая  | Заменить только это совпадение текстом из поля замены. Совпадения в столбце исходного текста заменить нельзя.                                                                                                                                       |
| Средняя | Поместить текст из поля замены на место ячейки (см. [помещение](#помещение)). Для совпадения в столбце перевода вас сначала попросят подтвердить; для совпадения в столбце исходного текста вы выбираете столбец перевода, в который его поместить. |

## Замена

Кнопка замены просит подтверждение, сообщая, сколько ячеек и файлов она затронет, а затем заменяет каждое совпадение текстом из поля замены во всех файлах, которые охватывает поиск - а не только в видимых результатах. Замена меняет только текст перевода, никогда исходный текст, и требует выбора конкретного столбца перевода в **столбце** - "Все столбцы" и "Крайний столбец" не принимаются. Если поле замены пустое, вас спросят, действительно ли вы хотите заменить совпадения на ничего.

**Перед глобальной заменой** сначала запустите поиск, просмотрите панель результатов и убедитесь, что это действительно то, что вы хотите изменить. Одно неправильное совпадение, проскочившее при замене по всему проекту, сложно заметить потом. Если хотите делать это по одному, кликайте правой кнопкой мыши по отдельным результатам вместо глобальной кнопки.

## Помещение

С помещением стоит быть осторожным: оно **перезаписывает ячейку перевода** в каждой строке, исходный текст которой совпадает с текстом поиска, заменяя её текстом из поля замены - даже если в ячейке уже был перевод.

Помещение - это переключатель рядом с кнопкой замены: пока он включён, кнопка замены выполняет помещение вместо замены. Как и замена, оно требует выбора конкретного столбца перевода в **столбце**, и именно в этот столбец оно записывает.

Помещение ищет совпадения только в _исходном_ тексте, так что оставьте локацию на "Искать везде" или "Только исходный текст" - с "Только перевод" оно ничего не найдёт. Оно также сопоставляет исходную строку **целиком**, от начала до конца, а не подстроку - так что поиск `Привет` совпадёт только с исходной строкой, которая равна ровно `Привет`, но не с `Привет, мир!`. Чтобы сопоставить изменяющееся окончание, используйте регулярное выражение с жадным квантификатором, например `Привет .+` совпадёт с `Привет мир`, `Привет Rust`, `Привет что угодно` и так далее.

Как и с заменой: сначала поиск, затем проверка панели результатов, и только потом помещение для всего. Кликните средней кнопкой мыши по одному результату, чтобы поместить текст только в эту строку.

## Регулярные выражения

Приложение использует [реализацию регулярных выражений Qt](https://doc.qt.io/qt-6/qregularexpression.html), которая по сути является [PCRE2](https://www.pcre.org/current/doc/html/pcre2syntax.html) - юникод полностью поддерживается.

В тексте замены/помещения доступны следующие подстановки:

| Последовательность | Вставляет                                         |
| ------------------ | ------------------------------------------------- |
| `` \` ``           | Текст перед полным совпадением.                   |
| `\'`               | Текст после полного совпадения.                   |
| `\+`               | Последнюю захваченную группу.                     |
| `\{n}` / `\{nn}`   | Захваченную группу `n`. `\0` - полное совпадение. |
| `\\`               | Просто `\`.                                       |

Если вам нужен простой способ полностью откатить замены по регулярным выражениям, сначала проведите их где-нибудь вне программы (в текстовом редакторе, скриптом) - приложение не хранит историю замен/помещений.
