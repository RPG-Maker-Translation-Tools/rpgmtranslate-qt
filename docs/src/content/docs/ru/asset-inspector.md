Просмотрщик ассетов открывается кнопкой ![](../assets/stock_media.svg). Он позволяет просматривать ассеты проекта, не выходя из приложения.

## Поиск ассета

Ассеты сгруппированы в дереве по категориям - аудио, данные, изображения, иконки, шрифты, видео, сохранения, JS - кликните по любой записи, чтобы просмотреть её. Подпапки (например `img/characters`) являются ветками своей категории. Поле фильтра над деревом сужает его по названию файла по мере ввода, что важно, когда в одной категории проекта сотни файлов.

Все движки используют одни и те же категории и распознают одни и те же виды файлов; движки отличаются только тем, где ищутся файлы. У RPG Maker 2000/2003 нет отдельных папок для ассетов, так что поиск идёт по всей папке проекта (собственные папки приложения `.rpgmtranslate` и `translation` пропускаются). Всё, что перечислено, можно открыть.

У каждого просмотра есть кнопка **Открыть расположение**, открывающая папку файла в файловом менеджере, и кнопка **Открыть в стандартном приложении**.

## Просмотрщик изображений

Изображения PNG, JPEG и BMP, зашифрованные (MV/MZ) или обычные - ничего не нужно расшифровывать вручную.

## Просмотрщик кода

Для файлов JSON и JavaScript, а также для бинарных файлов данных и сохранений движков (`.rxdata`, `.rvdata`, `.rvdata2`, `.lmu`, `.ldb`, `.lsd`...), которые показываются в виде читаемого JSON. Файл `Scripts` RPG Maker XP/VX/VX Ace показывается как код на Ruby. Подсветка синтаксиса автоматическая, кроме файлов больше 1 МБ, которые показываются без неё.

Кнопка **Отформатировать** на панели инструментов переформатирует содержимое в читаемый вид: JSON всегда, JavaScript и Ruby в билдах с `ENABLE_JS_FORMATTING`/`ENABLE_RUBY_FORMATTING` (обе включены по умолчанию).

Поле поиска находит текст в файле, по желанию с учётом регистра, по целым словам или по регулярному выражению, а кнопки со стрелками переходят между совпадениями. Поиск показывает не больше 5000 совпадений.

## Медиа плеер

Проигрывает аудио и видео, зашифрованные или обычные. Клик по полосе прогресса или клавиши перематывают, а ползунок задаёт громкость. Видео, превышающее окно, уменьшается до его размера.

Какие форматы можно проиграть, определяется FFmpeg, с которым собрано приложение. Официальные релизы под Windows используют подходящую сборку FFmpeg; скрипты для её сборки находятся в [этом репозитории](https://github.com/savannstm/personal) (`dev/build-dev-libraries`), смотрите в них точный список включённых декодеров и демуксеров. Если файл есть в списке, но не проигрывается, скорее всего его формат не включён в сборку.

### MIDI

Старые игры на RPG Maker и Wolf RPG часто используют музыку в MIDI. MIDI файл содержит только ноты, так что приложению нужен General MIDI SoundFont, чтобы превратить их в звук. Мы его не поставляем - положите `.sf2` файл с названием `soundfont.sf2` в папку данных приложения - по умолчанию рядом с исполняемым файлом (см. [установку](installation.md#файлы-данных-программы)). Без него при открытии MIDI файла будет показан точный путь, по которому ожидается этот файл.

[GeneralUser GS](https://www.schristiancollins.com/generaluser) - хороший бесплатный универсальный вариант. Но учтите, что старые игры делались специально под Windows с её стандартным проприетарным SoundFont, так что любой другой SoundFont **не** даст того же звука, что и в самой игре. SoundFont влияет только на то, как MIDI файлы звучат в просмотрщике, а не в игре.

## Просмотрщик шрифтов

Показывает образец текста, отрисованный выбранным шрифтом, и список поддерживаемых им систем письма. Введите свой текст образца и измените его размер на панели инструментов. Проверьте это, прежде чем полагать, что шрифт поддерживает ваш язык - шрифт, который хорошо выглядит с латиницей, может не иметь глифов, которые действительно нужны вашему переводу.
