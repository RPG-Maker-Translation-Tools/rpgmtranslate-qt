# 任务

长时间运行的操作（读取项目、写回、搜索、替换、批量翻译/脚本、全局检查、清除、提取存档、导出/导入）以**任务**的形式运行：在 UI 线程之外执行，集中追踪，并在任务列表中显示。

## 任务显示位置

顶部栏的按钮（空闲时显示"No tasks"）用于打开任务列表。每个正在运行的任务显示其名称和进度条（`已完成/总数` 项目）。支持中止的任务还会在进度条旁边显示一个中止按钮。

## 多个任务同时运行

任务不限于一次只能运行一个——多个任务可以真正并行运行，每个任务在自己的后台线程上。两个任务是否可以同时运行取决于它们操作的内容，而不仅仅是应用是否"忙"：

- **写入、搜索、导出和全局检查** 只读取项目状态，因此这些操作的任意组合可以同时运行——在写入时搜索、在写入时全局检查等。
- 其他所有任务（**读取、清除、提取存档、替换、批量脚本、批量翻译、导入**）会修改项目状态，因此在完成前会阻塞所有其他操作，包括它自己的另一个实例。

如果您尝试启动一个不允许与当前运行任务同时运行的任务，您会收到一条通知，指出是哪个任务在阻挡，而不是让新任务无声地排队或失败。

## 中止

搜索、替换、批量脚本、批量翻译、全局检查、导出和导入可以在任务列表中通过其中止按钮在运行中途中止。读取、写入、清除和提取存档一旦开始就无法中断——请让它们完成。
