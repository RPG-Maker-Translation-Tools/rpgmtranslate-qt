# Rvpacker 功能

`rvpacker-txt-rs-lib` 负责从 RPG Maker 游戏读取文本并写回。它包含四个部分。

## 读取

读取在需要时解密源存档，解析游戏数据文件，并生成你编辑的纯文本文件。

首次打开新项目时，读取选项对话框会在任何解析之前自动弹出——你需要配置它并点击"应用"继续。之后，你可以从 `rv` 按钮手动触发重新读取（从其菜单中选择"读取"）来重新解析项目，例如游戏更新后源文件发生变化时。这会打开相同的对话框：

| 选项 | 功能 |
| ---- | ---- |
| 读取模式 | **默认**在源文件自上次读取以来未变化时不做任何操作——使用**强制**可强制重新读取。**追加**/**强制追加**在保留现有翻译的同时添加新发现的文本。 |
| 重复模式 | **去除重复**（推荐）会折叠跨地图和事件的重复行。**允许重复**保留每个出现的独立记录。系统、脚本和插件文件始终表现为"允许"模式，不受此选项影响。 |
| 文本编码 | 强制使用指定代码页解码文本，而非自动推断。适用于 RPG Maker 2000/2003、XP 和 VX——这些是传统引擎，没有自己的编码，默认使用系统代码页（与 VX Ace、MV 和 MZ 不同）。留空以自动推断。如果下方游戏标题包含原生非 ASCII 字符，可帮助确定正确编码。 |
| 忽略 | 跳过 `.rvpacker-ignore` 文件中列出的条目（见[清除](#purge)。 |
| 跳过已废弃 | 删除上一次读取中已不存在的条目，而非保留它们。 |
| 解析地图事件 | 同时提取地图事件元数据——事件 ID、名称和 X/Y 位置——以及对话文本。 |
| 从 ini 文件读取标题 | 对于 RPG Maker 2000/2003/XP/VX/VX Ace，游戏标题并不总是在系统文件中。启用此项可从 `Game.ini`（XP/VX/VX Ace）或 `RPG_RT.ini`（2000/2003）获取，取存在的那个。标题使用上方的"文本编码"字段解码——如果显示为乱码，即为编码错误的提示；如果包含原生非 ASCII 字符，还可帮助你确定正确的编码。 |

对话框中的文件选择按钮允许将手动重新读取限定于特定文件，而非整个项目。

## 写入

写入通过 ![](./assets/manufacturing.svg) 按钮访问。它将你当前的翻译写回游戏文件，使其可以运行。

对于 2000/2003/XP/VX 引擎，有一个非常重要的写入设置——文本编码。阅读[设置](./settings.md#project)了解更多。

## 清除

清除会删除未翻译的行，并可选择创建 `.rvpacker-ignore` 文件，使这些行在下次读取项目时不再出现。

## 导出 / 导入

这会将你的翻译文件转换为 CSV、XLSX、XML、JSON 或 YAML 格式并反向转换——适用于在电子表格中编辑、发送给不想运行该应用程序的人，或将快照存档到应用程序自身格式之外。

选择一个格式，选择一个文件夹（导出目标，导入来源），使用文件选择按钮选择要包含的文件，然后执行导出或导入。每个翻译文件在该文件夹中变成所选格式的一个文件，名称相同但扩展名不同（例如 `actors.txt` -> `actors.csv`）——导入时也期望相同的命名方式。

**导入会覆盖相应翻译文件的内容**，因此在运行前请确保你要导入的文件夹中确实包含你所需的内容。
