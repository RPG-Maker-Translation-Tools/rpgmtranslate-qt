# 资源检查器

点击 ![](./assets/stock_media.svg) 按钮打开资源检查器。它让您无需离开应用即可浏览和预览项目中的资源。

## 查找资源

资源按类别（音频、数据、图片、图标、字体、视频、JS）在树形结构中分组——点击任意条目可预览。树形结构上方的筛选框支持按文件名即时过滤，这对于一个类别中有数百个文件的项目非常重要。

## 图片查看器

支持加密的（`.png_`、`.rpgmvp`）和解密的（`.png`、`.jpg`）图片——无需手动解密。

**操作：** 滚动缩放，左键拖动平移。

## 代码查看器

用于 JSON、JavaScript 和 Ruby 文件（引擎的数据文件和脚本）。语法高亮是自动的——直接打开文件即可。

对于 JSON 文件，工具栏中会出现一个 **"美化"** 按钮，将原始内容重新格式化为可读的格式。JavaScript/Ruby 的美化功能尚未实现。

## 媒体播放器

播放音频和视频，支持加密（`.ogg_`、`.rpgmvo`、`.m4a_`、`.rpgmvm`）和解密（`.ogg`、`.m4a`、`.mp4`、`.webm`）格式——同样无需手动解密。

**操作：** 播放/暂停，以及一个可拖动的进度条——拖动并释放以跳转到指定位置。

## 字体查看器

显示用所选字体渲染的示例文本，以及它支持的书写系统列表。在假设某字体支持您的目标语言之前请先检查此处——一个看起来适合拉丁文本的字体可能缺少您翻译实际需要的字形。
