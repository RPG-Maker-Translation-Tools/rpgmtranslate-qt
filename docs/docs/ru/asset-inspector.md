# Просмотрщик ассетов

Просмотрщик открывается через кнопку ![](./assets/stock_media.svg). Он позволяет вам изучать и осматривать ассеты проекта без выхода из приложения.

## Поиск ассета

Ассеты сгруппированы по категориям - аудио, data, изображения, иконки, шрифты, видео, JS - нажмите на любую категорию, чтобы посмотреть файлы. Ввод для фильтрации над списком показывает только файлы которые совпадают, что важно когда в проекте сотни файлов.

## Просмотрщик изображений

Поддерживает как зашифрованные (`.png_`, `.rpgmvp`), так и расшифрованные (`.png`, `.jpg`) изображения - нет нужды что-то вручную распаковывать.

**Управление:** колёсико для скролла, правый клик и перемещение для осмотра.

## Просмотрщик кода

Для JSON, JavaScript и Ruby (файлы данных и скрипты RPG Maker). Подсветка синтаксиса автоматическая - при открытии файла.

Для каждого вида кода присутствует кнопка для форматирования в читабельный вид.

## Медиа плеер

Проигрывает как аудио, так и видео - зашифрованное (`.ogg_`, `.rpgmvo`, `.m4a_`, `.rpgmvm`) и расшифрованное (`.ogg`, `.m4a`, `.mp4`, `.webm`).

**Управление:** проигрыш/пауза, изменяемый ползунок прогресса.

## Просмотрщик шрифтов

Показывает примерный текст для выбранного шрифта, а также системы написания которые он поддерживает. Это необходимо для проверки того, поддерживает ли вообще шрифт ваш язык.
