# Редактирование текста

После открытия вкладки ![](./assets/menu.svg), вам будет представлена таблица перевода, позволяющая редактировать ячейки с переводом как обычные текстовые редакторы.

В данных редакторах присутствуют значимые функции.

## Машинный перевод

Если вы настроили точки для [одиночного перевода](./settings.md#translation), они будут использованы чтобы перевести исходный текст соответствующий редактируемой ячейке перевода. Результаты показываются в ![](./assets/translate.svg) меню переводов - нажатие на один из результатов вставит перевод в ячейку, которую вы редактируете.

## Вкладки

Правый клик по ряду открывает меню, в котором можно выбрать пункт "Добавить в закладки". Закладки отображаются в ![](./assets/bookmarks.svg) меню закладок, и они сгруппированы по файлу - кликните на закладку чтобы перейти к нужному ряду.

## Линтинг

Линты в основном имеют какой-то особый способ подсвечивания текста после фокусировки ячейки перевода (например особый цвет текста, фона, волнистая линия) и/или они отображаются в меню линтинга.

Меню линтинга доступно через кнопку ![](./assets/lab_profile.svg) button. Оно предоставляет:

- "Выключить линтинг" - глобальный переключатель который полностью отключает все опции.
- Отдельные флажки для пробелов/пунктуации/несовпадения тегов/правописания/LanguageTool/глоссария.
- "Линты" - открывает меню чтобы переключить отдельные линты плагинов/тегов, а также пользовательские линты.
- Кнопка выбора файлов, чтобы ограничить проверку только выбранными файлами.
- "Глобальная проверка" - прогоняет каждый включенный линт через выбранные файлы в качестве фоновой задачи, вместо линтинга только редактируемой в данный момент ячейки.

Наведение курсора на линт при редактировании текста показывает подсказку с деталями о линте. Для текстовых кодов и прочих последовательностей из плагинов  (`\C[x]`, `\I[n]`, `\N[n]`, ...) подсказка показывает реальные данные - настоящее имя персонажа, предмета, навыка, иконки, цвета и так далее. Некоторые подсказки включают в себя кликабельную ссылку для применения предложенного исправления.

### LanguageTool

Если вы настроили [LanguageTool](./settings.md#languagetool), он будет использован для линтинга перевода.

### Проверка правописания

RPGMTranslate поддерживает проверку правописания по умолчанию, благодаря библиотеке Nuspell.

Для информации о том как найти, установить и активировать словари, прочтите [настройки правописания](./settings.md#spell-check)

Учтите, что CJK пока не поддерживается.

### Глоссарий

Если вы настроили глоссарий [Glossary](./glossary.md), приложение будет проверять консист терминов и несовпадения между исходным текстом и переводом.

### Плагины и прочее

RPGMTranslate предоставляет встроенный линтинг для всех плагинов описанных на вики от Yanfly, а также некоторые линты не относящиеся к плагинам.

Перечислять их все здесь будет очень долго, и синхронизировать списки между исходным кодом и документацией будет практически невозможно. Вы можете проверить, какие плагины поддерживаются в исходном коде:

- `src/Lints/CommentTags.inl`
- `src/Lints/Notetags.inl`
- `src/Lints/PluginCommands.inl`
- `src/Lints/TextCodes.inl`

Каждый отдельный линт может быть включён и отключён в меню через кнопку "Линты".

Что касается других плагинов, вот их список:

- Пробелы
    - Начальные пробелы - добавляет линт в меню, подсвечивает начальные пробелы.
    - Конечные пробелы - добавляет линт в меню, подсвечивает конечные пробелы.
    - Продолжительные пробелы - добавляет линт в меню, подсвечивает продолжительные пробелы.
    - Какие символы считаются пробелами для этих линтов можно настроить, прочтите [Перевод > Настройки линтов](./settings.md#lints).
- Незакрытая пунктуация - добавляет линт в меню, подсвечивает незакрытую пунктуацию, вроде незакрытых кавычек.
- Несовпадение тегов в исходном тексте и переводе - добавляет линт в меню когда исходные теги и теги в переводе различаются. Это происходит когда перевод не имеет такие же теги как в исходном тексте.

## Горячие клавиши

- Shift + ↓ - Перейти к следующему ряду (вниз)
- Shift + ↑ - Перейти к предыдущему ряду (вверх)
- Shift + ← - Перейти к левому столбцу перевода
- Shift + → - Перейти к правому столбцу перевода
- Ctrl + ↑ - Перейти к высшему ряду
- Ctrl + ↓ - Перейти к низшему ряду
- Правый клик по исходному тексту - Скопировать исходный текст

## Массовый выбор

Вы можете выбрать несколько ячеек с переводом кликнув на одну из них и продлив выделение кликнув на другую с зажатой клавишей Shift.

Массовые копирование, вырезание и вставка поддерживаются.
