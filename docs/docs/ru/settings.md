# Настройки

![](./assets/settings.svg) Настройки открываются через меню "Файл".

Окно разбито на пять секций, указанных справа: **Основные**, **Вид**, **Управление**, **Перевод**, **Проект**. Настройки сохраняются после закрытия проекта - если поле имеет неверное значение (e.g. например период резервного копирования вне диапазона), окно откажется закрываться и укажет вам на ошибочное поле.

Основные настройки, вид и управление хранятся глобально. Настройки перевода и проекта хранятся **отдельно на проект**, так что разные проекты могут использовать разные точки перевода, языки, конфигурации линтинга.

## Основное

### Резервное копирование

| Параметр                      | Описание                                                                |
| ----------------------------- | ----------------------------------------------------------------------- |
| Включено                      | Включает или отключает автоматическое резервное копирование проектов.   |
| Период резервного копирования | Как часто создается резервная копия, в секундах (60-3600).              |
| Максимум резервных копий      | Сколько резервных копий хранить на проект перед удалением самой старой. |

Чтобы восстановить копию, используйте меню `Файл > Загрузить резервную копию`. Оно перечисляет резервные копии проекта по дате и предупреждает, что загрузка **перезапишет вашу текущую несохраненную работу** - сначала убедитесь, что вы этого хотите.

### Обновления

| Параметр                           | Описание                                                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Проверка обновлений                | Проверяет новую версию приложения при запуске.                                                                 |
| Проверка обновлений файлов проекта | Проверяет, изменились ли файлы игры с момента последнего чтения, и предлагает перечитать их при необходимости. |

### Git

Данные об авторе используются при коммите в встроенном [гит клиенте](./git.md).

| Параметр                              | Описание                                                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Использовать конфигурацию репозитория | Если репозиторий уже имеет установленные данные об авторе в своем `git config`, использовать их вместо полей ниже. |
| Имя / почта                           | Данные об авторе для коммита, если не используется `git config`.                                                   |

| -------------------------------- | ------------------------------------------------------------------------------------ |
| Шрифт таблицы переводов / размер | Шрифт и размер (8-96 пт) для использования в таблице переводов.                      |
| Стиль                            | Влияет на внешний вид кнопок, списков и других элементов.                            |

## Управление

Горячие клавиши для открытия панелей и меню. Кликните на поле горячей клавиши и нажмите нужную комбинацию.

| Действие          | По умолчанию |
| ----------------- | ------------ |
| Панель поиска     | `Ctrl+R`     |
| Панель вкладок    | `Tab`        |
| Перейти на строку | `Ctrl+G`     |
| Пакетное меню     | `Ctrl+B`     |
| Меню закладок     | `Alt+B`      |
| Меню линтинга     | `Ctrl+M`     |
| Меню глоссария    | `Alt+B`      |
| Меню переводов    | `Ctrl+S`     |

Если одна горячая клавиша назначена на два действия сразу, попытка закрыть окно провалится и вам будет выведена ошибка.

## Перевод

Это самый большой раздел. Здесь настраиваются точки машинного перевода, LanguageTool и система линтинга.

API ключи никогда не записываются в `settings.json` - они хранятся в собственном хранилище учетных данных ОС (Windows Credential Manager или Secret Service keyring на Linux), и считываются только при необходимости.

### Точки перевода

Точки перечислены слева этого раздела; добавляйте или удаляйте их кнопками над списком. Каждая точка имеет:

| Параметр                      | Описание                                                                                                                                                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Переводить при редактировании | При включении редактирование ячейки перевода также переводит исходный текст через эту точку и показывает результат в меню переводов. Осторожнее с платными LLM API - каждое редактирование расходует токены. |
| Использовать глоссарий        | Отправляет термины вашего [глоссария](./glossary.md) точке перевода при переводе.                                                                                                                            |

Дальше поля зависят от типа точки:

- **Google** - бесплатно, настройка не требуется.
- **Yandex** - требует API ключ и ID папки Yandex Cloud.
- **DeepL** - требует API ключ.
- **LLM точки** (совместимые с OpenAI, Ollama и подобные) имеют один набор полей:
  - API ключ / базовый адрес - учетные данные и адрес сервера. API ключ опционален для локальных поставщиков.
  - Модель - загружается через "Проверить ключ", который проверяет учетные данные и заполняет список моделей.
  - Лимит токенов / Лимит выходных токенов - бюджеты запроса и ответа (1000-65536).
  - Температура - случайность выборки (0.0-2.0).
  - Расширенное мышление / Уровень усилий - включает расширенное мышление на моделях, которые его поддерживают, и сколько усилий потратить.
  - Системный промпт / Системный промпт для перевода при редактировании - инструкции, отправляемые модели; каждый можно сбросить на встроенное значение по умолчанию.

Поставщики, которые не в списке типов (например [OpenRouter](https://openrouter.ai/)), работают через универсальный тип **Совместимый с OpenAI** - просто укажите базовый адрес на совместимую с OpenAI точку поставщика (для OpenRouter это `https://openrouter.ai/api/v1`) и используйте ваш API ключ от этого поставщика.

### LanguageTool

Настраивает проверку грамматики [LanguageTool](https://languagetool.org/), используемую для [линтинга](./text-editing.md#linting). И локальный сервер, и платный хостинг поддерживаются, но только локальный сервер был протестирован.

| Параметр                                                         | Описание                                                                                                                   |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Базовый адрес                                                    | Ваш сервер LanguageTool, локальный или хостинг. "Проверить соединение" проверяет его доступность.                          |
| Имя пользователя / API ключ                                      | Требуется только для платного хостинга, для доступа к Premium.                                                             |
| Родной язык                                                      | Ваш родной язык, для проверки фальшивых друзей в некоторых языковых парах.                                                 |
| Только разрешенные                                               | При включении проверяются только явно указанные ниже категории/правила - все остальное игнорируется.                       |
| Включенные/отключенные категории, включенные/отключенные правила | ID правил/категорий через запятую для сужения или скрытия проверяемых элементов.                                           |
| Предпочтительные варианты                                        | Региональные варианты написания через запятую, которые LanguageTool должен предпочитать (например `en-US` вместо `en-GB`). |
| Словари                                                          | Дополнительные словари через запятую для использования слов. Оставьте пустым для использования по умолчанию.               |
| Строгий режим                                                    | Включает дополнительные правила, в основном полезные для формального текста.                                               |

### Линтинг

Все здесь можно переключать по элементам из кнопки "Линтинг" в [меню линтинга](./text-editing.md#linting) - это лишь место где вы их настраиваете и редактируете, а не переключаете.

- **Линты последовательностей** - четыре фиксированных таблицы (Текстовые коды, Note тэги, команды плагинов, Comment тэги), где перечислены все встроенные шаблоны плагинов/тегов, которые распознает RPGMTranslate, сгруппированные по категориям. Каждой строке можно дать пользовательский цвет выделения.
- **Пользовательские линты** - ваши собственные шаблоны линтинга в редактируемой таблице: последовательность для совпадения, всплывающая подсказка, чувствительность к регистру и опциональный цвет выделения. Дважды кликните ячейку для редактирования. Пользовательские линты можно экспортировать и импортировать из JSON файла для резервной копии или обмена.
- **Прочее**:
  - Замены последовательности - таблица последовательностей символов, которые молча заменяются при вводе (например `<<` -> `«`), полезно для не-ASCII пунктуации, которой нет на клавиатуре. Несколько общих предзаполнены но отключены по умолчанию.
  - Символы пробелов - какие кодовые точки Unicode (`U+XXXX`, через запятую) считаются пробелом для линтов ведущих/конечных/соседних пробелов.

## Проект

Хранятся отдельно на проект.

| Параметр                      | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Подсказка длины строки        | Рисует тонкую красную линию в ячейке перевода на этом количестве символов (0-255) как направляющую для переноса строк.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Исходный язык / Язык перевода | Исходный и целевой языки, используются для сопоставления терминов [CAT](https://en.wikipedia.org/wiki/Computer-assisted_translation). Ограничено языками поддерживаемыми нашей [библиотекой сопоставления текста](https://github.com/savannstm/language-tokenizer/blob/master/src/lib.rs#L139).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Словарь проверки правописания | Словарь для проверки. Ниже см. где его взять.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Кодировка для записи          | Кодировка по умолчанию не задана, из-за чего всегда записывается UTF-8 - оставьте так, если у вас нет полной уверенности, что нужно иное. Перевод, как правило, невозможно представить в исходной кодировке игры (в японской `Shift-JIS`, например, нет кириллицы для перевода на русский), и при принудительном указании неподходящей кодировки ошибки не будет - непредставимый символ незаметно заменяется на ссылку вида `&#1055;`, вставленную прямо в текст. Задавайте кодировку только если движок игры не умеет работать с юникодом - это верно для RPG Maker 2000/2003, XP и VX, которые выводят текст через устаревшую ANSI-кодировку ОС вместо декодирования UTF-8 - _и_ если письменность перевода умещается в выбранную кодировку. Тому, кто будет запускать переведённую игру, тогда тоже придётся выставить в системе (или через эмулятор локали) ту же кодировку; начиная с Windows 10 1903 включение чекбокса "Бета-версия: использовать Юникод (UTF-8) для поддержки языков во всём мире" в настройках региона позволяет UTF-8 по умолчанию работать и для этих движков без всего вышеперечисленного. VX Ace изначально ориентирована на юникод, так что для неё UTF-8 по умолчанию работает в любом случае. |

### Проверка правописания

RPGMTranslate не поставляется со словарями проверки правописания - поместите файлы `.aff`/`.dic` в `ПАПКА_ПРИЛОЖЕНИЯ/dictionaries` и они появятся в выпадающем списке выше. Источники:

- [Словари LibreOffice](https://github.com/LibreOffice/dictionaries)
- [Эта коллекция словарей](https://github.com/wooorm/dictionaries)

CJK пока не поддерживается.

### Проверка терминов CJK

[Совпадения по глоссарию](#проект) в японском, китайском и корейском нуждаются в словарях для разделения слов (так как в этих языках нет пробелов между словами), и RPGMTranslate их не поставляет - они имеют вес в сотни мегабайт и раздуют каждый релиз. Скачайте соответствующий архив из [страницы релизов Lindera](https://github.com/lindera/lindera/releases), распакуйте его, и закиньте распакованные файлы (`dict.trie`, `dict.words`, `metadata.json`, и т.д.) в `ПАПКА_ДИРЕКТОРИИ/lindera-dictionaries/<язык>`, чтобы `dict.trie` и прочие находились там - словарь будет автоматически подобран когда программа попытается его использовать, не нужно ничего перезапускать.

| Язык      | Папка                           | Архив для скачивания                                                               |
| --------- | ------------------------------- | ---------------------------------------------------------------------------------- |
| Японский  | `lindera-dictionaries/japanese` | `lindera-ipadic-neologd-*.zip` (лучшее качество) или `lindera-ipadic-*.zip` (хуже) |
| Китайский | `lindera-dictionaries/chinese`  | `lindera-cc-cedict-*.zip`                                                          |
| Корейский | `lindera-dictionaries/korean`   | `lindera-ko-dic-*.zip`                                                             |

Если нужная папка отстутствует или архив был неверно распакован, использование языка для проверки терминов не удастся с ошибкой.

### Контекст

Свободный текст, передаваемый точкам ИИ при переводе:

- **Контекст проекта** - общие параметры, тон, терминология, аудитория - применяется ко всему проекту.
- **Контекст файла** - выберите файл из списка, затем напишите контекст специфичный для него (имена персонажей появляющиеся только в этом файле, смены тона, ограничения, и т.д.).
