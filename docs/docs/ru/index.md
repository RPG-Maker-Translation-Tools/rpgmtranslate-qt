# RPGMTranslate

RPGMTranslate - это простой инструмент для перевода RPG Maker игр с открытым исходным кодом. Среди его основных преимуществ - невероятная производительность и простой текстовый формат файлов перевода.

Само приложение представляет собой портабельное приложение. Всё что приложение записывает остаётся рядом с ним - настройки, lock-файл, и так далее. Папка для данных приложения может быть изменена через переменную среды `RPGMTRANSLATE_DATA_DIR`, прочтите [установку](installation.md#runtime-data-files).

## Как начать

Чтобы начать переводить что-либо, вам лишь нужно открыть ![](./assets/folder_open.svg) папку содержащую RPG Maker игру. Более конкретно, папка должна содержать папку `data` (или `Data`), либо же архив RGSS (`Game.rgssad`, `Game.rgss2a`, `Game.rgss3a`).

Открыв проект впервые, вам высветится диалоговое окно с опциями чтения файлов игры - выберите опции (или оставьте стандартные) и нажмите применить. Прочтите [Rvpacker > Чтение](rvpacker.md#read) для понимания эффектов опций. После этого, приложение расшифрует архив если он существует, вытащит текст из data файлов, создаст папку `.rpgmtranslate` и откроект проект.

Отсюда вы можете начать делать всякое. Прочтите [установку](installation.md) и [редактирование текста](text-editing.md) - это лучшие места чтобы начать.
